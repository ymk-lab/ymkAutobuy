四種 Mode

每天只輸出一個持倉模式；次日開盤成交。

裁決優先序

由高到低；高優先級覆蓋低優先級。

  1. harsh_ret急跌 → 空手
  2. thrust指數衝刺 → 抱 ETF
  3. sticky選股黏不住 → 抱 ETF
  4. harsh_dd深回撤 → 空手
  5. mild輕度轉弱 → 空手
  6. index_lean指數偏強 → 抱 ETF
  7. stock_led + crowded集中領漲 → strong
  8. ers風險開且非指數偏強 → 選股
  9. cash其餘 → 空手

Sticky / Thrust

兩條鎖指數袖套，可蓋過 Mild 與滯後深回撤。

  • Sticky：領導股 60 日相對指數落後 ≤ −6%，確認 2 日，且站上 SMA50 → 鎖 bench；追上至 −2% 並確認 6 日，或急跌，才退出。
  • Thrust：指數短線大漲／自低點強彈（ret5≥4%、ret10≥7%、bounce20≥6%、或 ret20≥8%），且站上 SMA50 → 鎖 bench。

Mild / Harsh

防守層；唯有急跌能打斷 Sticky／Thrust。

  • mild：破 SMA50，或 dd60≤−6%，或 ret20≤−4% → 偏空手。
  • harsh_dd：dd60≤−18% → 鎖外空手。
  • harsh_ret：ret20≤−12% → 最高優先空手，當日斷 Sticky。

一整段

Structure Gate v8 是一套與股票代號無關的日頻路由器：每天只輸出一個持倉模式——cash 空手、bench 滿倉基準 ETF、ers 做剛相對指數轉強的個股、strong 做已確認的集中領導股——並在次日開盤依富途美股費用加 3bps 滑價成交。它先量測領導股相對指數的短窗與長窗超額軌跡，以及指數是否站上 SMA50、短線漲幅、回撤與廣度；若領導股長窗落後指數超過約 6% 且指數仍強，就進入 Sticky 「指數黏著」，強制抱 ETF；若指數本身短線大漲或自低點強彈（Thrust），同樣鎖抱 ETF。防禦上，破均線或溫和轉弱觸發 Mild、更深回撤觸發 harsh_dd，原則上空手，但 Sticky／Thrust 可以蓋過這些中度防守；唯有 ret20 急跌（harsh_ret）擁有最高優先級，當日必須空手。因此 v8 不是單純買進持有，也不是純輪動，而是「能選股就選、選不過指數就退回指數、結構壞了就空手」。
