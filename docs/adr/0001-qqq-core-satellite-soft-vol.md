# QQQ 核心–衛星 + 輕量波動縮放（先 Sharpe）

我們要的是相近風險下優於買進持有，而不是「回撤好看但少賺」。第一版只做 QQQ、不槓桿；採用核心長抱參與上漲，並對核心施加 Soft Vol Overlay（高波動減倉但不歸零），衛星負責額外擇時／風險調節。評估時優先 Sharpe，再盡力改善最大回撤。

**Considered Options**
- 純 S12／L1+L4 全倉取代長抱：回撤常較好，但多次明顯踏空，不符合成功標準
- 純波動目標（整筆 0–100% 隨波動）：降險強，但仍可能大幅降低上漲參與
- 核心–衛星 + Soft Vol Overlay：保留大部分上漲 beta，又比滿倉多一層風險控制

**Status**: accepted
