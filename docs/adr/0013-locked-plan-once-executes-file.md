# Once executes the Locked Plan; it does not recompute

Signal writes an immutable plan after cash close. Once at 09:40 ET may only submit that file. Sleeve Notional and Buying-Power Cap are inputs to Signal, so changing them after the file exists waits for the next Signal. Trading Environment and Submit Gate still apply to the next Once without rewriting the plan, so a locked SIMULATE plan can be sent REAL if both locks are already on.
