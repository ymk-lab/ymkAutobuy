# 優先序改為：報酬先勝過基準，再談回撤

先前以 Sharpe 為第一優先，實務上收斂到防禦型 CoreSat／S12：回撤好看但常明顯輸給買進持有，不符合「要贏大盤」的新目標。

新優先序：
1. **第一優先**：評估窗總報酬高於同一標的買進持有（beat benchmark）。無槓桿時，這要求預設接近滿倉，只在高置信度風險關閉時減倉，並盡快回到滿倉。
2. **第二優先**：在已勝過（或最接近勝過）基準的候選中，選擇最大回撤較淺者。

因此退役「核心最低 35% 長抱 + Soft Vol 常態縮倉」作為預設書；改採進攻型 **BeatBench**：預設 100% 多頭，僅在趨勢破壞／嚴重度風險訊號時降倉或空手，風險解除後快速回到滿倉。

**Status**: accepted
